# 板凳龙大作战（单人 Demo）

面向课堂和希沃白板的 60 秒像素风小游戏。当前版本先提供单人挑战，双人依次 PK 将在后续版本加入。

## 玩法

- 板凳龙会自动前进，玩家只负责转向。
- 触控方向键位于地图正下方，也支持键盘方向键和 WASD。
- 转向输入会被立即缓存，并在 100ms 内完成下一次格子转向。
- 普通板凳增加 1 节，地图尽量始终保持 5 个。
- 龙珠增加 2 节，约每 12 秒出现一次，约 7 秒后消失。
- 米色村道是唯一可通行区域。
- 绿色草地、房屋、稻田、竹林、祠堂和院墙都会触发碰撞。
- 碰撞不会死亡，但会停顿 0.5 秒并记录一次碰撞。
- 如果进入真正的死胡同，惩罚结束后会沿来路快速退回最近岔路口，并自动朝最近道具方向继续。
- 60 秒结束后显示最终长度和碰撞次数。

## 打开游戏

现在可以直接双击项目根目录中的 `index.html` 开始游戏，无需先启动服务器。

开发调试时也可以使用本地静态服务器：

```powershell
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000/
```

游戏本身不依赖 Node.js、后端服务、数据库或联网资源。

## 运行测试

测试使用 Node.js 自带的测试运行器，不需要安装第三方依赖：

```powershell
npm test
```

`npm test` 会先根据 `js/` 中的模块源码重新生成兼容双击打开的 `js/game.bundle.js`，再运行全部测试。单独生成兼容入口可运行：

```powershell
npm run build
```

## GitHub Pages

项目可以直接从仓库根目录发布：

1. 将整个项目推送到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 选择从主分支根目录发布。
4. 保存后等待 Pages 地址生成。

所有运行文件均为静态 HTML、CSS 和 JavaScript。

## 主要文件

```text
index.html          页面与游戏界面
styles.css         16:9、触控和像素风样式
js/config.js       可调整的游戏数值
js/map.js          28×14 乡村道路迷宫
js/game-engine.js  移动、碰撞、计时和道具规则
js/renderer.js     Canvas 像素绘制
js/input.js        触控和键盘输入
js/screens.js      页面切换与结果显示
js/main.js         浏览器启动和游戏循环
tests/             自动逻辑与静态结构测试
```

## 当前范围

当前只实现单人 60 秒挑战。后续双人 PK 可以复用现有种子随机系统，让两名玩家使用同一地图和同一刷新序列。
